NeuroFusion Living Journal update

Adds an elegant member-only Journal card grid and full article reading view. Uses existing nf_content data and the existing /members/content endpoint. Owner can preview drafts; paying members see published articles only. No SQL changes. No changes to Stripe, login or permissions.

Deployment: replace existing repository files with this package, commit and push via GitHub Desktop. Then sign in as owner, click Journal in the left navigation, and open the saved Heartbreak draft. It should appear as a formatted article.

Note: pastel icon panels are used, not uploaded cover images. Image upload remains future work.
